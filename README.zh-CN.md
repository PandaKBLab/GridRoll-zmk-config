# GridRoll

[English](README.md) · **简体中文** · [日本語](README.ja.md) · [Deutsch](README.de.md)

PandaKB GridRoll 的 ZMK 固件：47 键、左旋钮、右 PAW3222 轨迹球，支持 USB／蓝牙、ZMK Studio 和 DYA Studio。**右侧连接电脑，左侧无线连接右侧**；设备名称均为 **GridRoll**。本仓库仅含固件与使用文档，不分发 PCB、原理图、布线或内部电路资料。

## 下载与更新

在 [Actions](https://github.com/PandaKBLab/GridRoll-zmk-config/actions/workflows/build.yml) 选择成功运行，只下载一个 **GridRoll-firmware** ZIP，包内仅：

- GridRoll-left.uf2

- GridRoll-right.uf2

- GridRoll-settings-reset.uf2

分别烧录对应侧正常固件。**普通更新不要刷 reset**，它会清除设置和配对。首次安装参照[启动程序流程](docs/first-flash.md)；产物保留 30 天，编译通过不代表实物验收通过。

## 四层默认配列

| 层 | 用途与进入方式 | 旋钮顺时针／逆时针 |
|---|---|---|
| L0 Base | QWERTY，左空格、右回车均为普通按键 | 上滚／下滚 |
| L1 Mouse | 拨球自动进入，或 Fn+B 手动进入、Esc 退出 | 上滚／下滚 |
| L2 Symbols | 按住左空格左边的 Symbols | 上滚／下滚 |
| L3 Function | 按住右回车右边的 Fn，同时作为轨迹球滚动层 | 音量加／减 |
| L4～L7 | 可编辑空层，所有键和旋钮均无动作 | 无 |

基础层底行：Ctrl、Alt、GUI、旋钮中键、Symbols、**空格**｜**回车**、Fn、轨迹球开口、左、下、右。原第三行右端回车改为右 Shift。[查看全部键值与八张键位图](docs/keymap.md)。

**保存过的 Studio 布局不会被刷机覆盖。** 采用这次四层布局前，先导出旧布局，再在 **ZMK Studio 恢复默认键位并保存**，不用清除配对。DYA 旋钮参数独立保存：L0～L2 设为上下滚轮，L3 音量加减，L4～L7 无动作；其余参数按需保留。

## 轨迹球

默认采用已确认的原生 **798 CPI，约 800 DPI**，不做额外补偿。DYA 正常倍率为 1/1 时，L1 **左手第 4 行第 6 列（左空格位置）**按住为 1/4 速度，等效约 **200 DPI**，松开恢复。自定义 DYA 倍率会改变等效速度。

J 左键、K 右键、H 中键、L 后退、分号前进；U/I 上下滚轮、O/P 横向滚轮。**L1 按住 M** 或基础层按住 Fn 时，轨迹球通过独立 scroll 处理器滚动。

有效拨球在 **200ms 打字保护**之外进入 Mouse；停止鼠标操作 **1200ms** 后退出，拖拽／修饰键／精细键按住时不超时；普通透明打字键退出，Esc 回基础层。Fn+B 的手动 Mouse 由 Esc 退出。保留 DYA mouse 临时层启用、目标 1、保护 200、退出 1200；不新增空闲轮询。

## 有线、蓝牙与 Studio

与右侧 GridRoll 配对。Fn+A/S/D/F/G 选择主机槽 0～4；需要重配当前槽时才用 Fn+Z。**Fn+X 选有线，Fn+C 选蓝牙**。USB 被电脑识别后自动优先有线，充电器不强制切换；手动蓝牙保持到下一次 USB 接入，拔线回退已连接蓝牙。

**两种 Studio 始终免解锁**，空闲／断连不重新上锁；浏览器串口或蓝牙授权仍需由用户选择。有线设置连接右侧 USB、选 USB 输出及对应串口，关闭占用同一串口的其他网页。

无线 DYA 设置：先配对到当前电脑并选择蓝牙输出（Fn+C），按 **Fn+V** 开放最长 **60s** 的发现窗口，再点 DYA 蓝牙连接并重新扫描。主机新连接或从 USB 选到 BLE 也会开放一次。空闲、USB 输出、断开或到期关闭额外广播；普通操作不会反复续期，结束广播不主动断开已建立的设置会话。**这是发现键，不是解锁键。**

旧固件连接电脑后停止广播，会让正常打字的键盘在网页设备选择框中消失。本次增加限时已连接广播与 Studio UUID 扫描响应。Windows／浏览器实际连接和保存仍需实机验证，不能以编译通过代替。[无线步骤与限制](docs/studio-wireless.md)。DYA mouse／scroll、逐层旋钮与标准 Studio 键位编辑保留，CI 检查三个固定扩展协议；未实现的传感器图像功能不包含在内。

## 指示灯、省电与唤醒

右红灯：等待连接 100ms/2s、最多 30s，成功亮 2s 后灭；各侧自身低电 ≤15% 时 100ms/30s、≥20% 解除，USB 抑制低电提示，空闲／休眠红灯关闭。蓝灯保持硬件充电周期指示，灭灯不能唯一证明充满。[详细规则](docs/led-status.md)。

原生电池采样活动时每 60s 一次，空闲停止、唤醒后刷新。无输入 **30s 空闲、15min 电池深睡**，分别按两侧按键唤醒；不承诺拨球或转旋钮从深睡唤醒。USB 供电侧保持唤醒，无线设置应在深睡前保存。

发现窗口不伪造输入来阻止休眠，也不持续广播；原有运动中断、BLE 8ms 合并报告及 USB 即时输出保留。实际电流、延迟与唤醒可靠性待测。
