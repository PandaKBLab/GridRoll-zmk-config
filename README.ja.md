# GridRoll

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語** · [Deutsch](README.de.md)

PandaKB GridRoll 分割キーボード用の ZMK ファームウェアです。47 キー、左側エンコーダー、右側 PAW3222 トラックボール、USB／Bluetooth、ZMK Studio と DYA Studio に対応します。

**右側が PC に接続する Central** で、左側は右側へ無線接続します。キーボード名、Bluetooth 名、USB 製品名はすべて **GridRoll** です。

このリポジトリにはファームウェア、ビルドツール、使用説明のみを含みます。PCB プロジェクト、回路図、配線、ネットリスト、内部回路資料は配布しません。ファームウェアに必要な GPIO 定義はボードのソースに保持します。

## ダウンロードと書き込み

1. [Build GridRoll firmware](https://github.com/PandaKBLab/GridRoll-zmk-config/actions/workflows/build.yml) で成功した実行を開きます。
2. ダウンロードする ZIP は **GridRoll-firmware** 一つだけです。内容は **GridRoll-left.uf2**、**GridRoll-right.uf2**、**GridRoll-settings-reset.uf2** の三つだけです。
3. 各側をブートローダーモードにし、左側に GridRoll-left.uf2、右側に GridRoll-right.uf2 をコピーします。設定初期化用イメージは通常使用には使えません。
4. GridRoll ブートローダーが未導入の場合は、[初回書き込み手順](docs/first-flash.md)を参照してください。初回書き込みパッケージは別途ビルドするもので、この ZIP には含まれません。

成果物の保存期間は 30 日です。ビルド成功はソフトウェア検証であり、実機試験の合格を意味しません。

## Bluetooth と Studio

PC は**右側の GridRoll** とペアリングします。見つからない場合は未使用のプロファイルを選ぶか、現在のプロファイルと PC 側の古いペアリングを削除してください。通常の更新では保存済みペアリングは消去されません。

標準 Planck 配置では **Lower + Raise** で System に入り、Q でプロファイル 0、Backspace で消去、Y で USB、U で BLE を選びます。PC が右 USB を認識すると USB 優先、抜線後は接続済み BLE に戻ります。充電のみでは切り替えず、手動 BLE 選択も可能です。保存済み配置は異なる場合があります。

[ZMK Studio](https://zmk.studio/) または [DYA Studio](https://studio.dya.cormoran.works/) では、**右側を USB 接続**し、USB 出力とシリアルポートを選択します。**編集は初めからロック解除状態で、解除キーは不要です。アイドルや切断でも再ロックしません。** 同じポートを使う他のページを閉じ、変更を保存してください。更新では Studio／DYA 設定を保持します。DYA で回転を手動補正していた場合は、その追加補正を解除してください。取り付け方向補正はマウス／スクロール処理より前に適用されます。

両方の UI でキー配置を編集でき、DYA では mouse／scroll と**各レイヤーのエンコーダー回転割り当て**も調整できます。基本レイヤーは時計回りでホイール下、反時計回りで上です。CI で三つの固定 DYA 拡張プロトコルとロック無効設定を確認します。未実装のセンサー画像等は含みません。

## 8 レイヤーの初期配置

標準は **Planck QWERTY / Lower / Raise** を 47 キーへ適用し、Mouse、Navigation、Scroll、Wireless、System の計 8 レイヤーです。Tab/Esc/Shift/記号/Enter は通常キーです。Lower + Raise で System に入り、旧 LiNEA40 コンボを削除しました。[全キー値・図・操作方法](docs/keymap.md)を参照してください。

## 自動 Mouse とホイール

有効なボール移動で即座に Mouse を有効化します。ただし直前 **200 ms** の打鍵中は誤動作を防ぎます。最後の移動、ホイール、マウス／修飾キー解放から **1200 ms** で終了します。ドラッグ中はタイムアウトせず、通常の透過文字キーまたは Esc で終了します。

**J=左、K=右、H=中クリック、L=戻る、セミコロン=進む。U/I=上下ホイール、O/P=左右ホイール。** M を押す間はボールスクロール、右 Space 長押しは手動 Mouse です。基本エンコーダーは時計回り下／反時計回り上の離散 1 ステップで、旧 20 ms 短押しの丸め落ちを解消します。

保存済み DYA 設定は独立します。旧値が残る場合は mouse Temp-layer を有効、レイヤー 1、保護 200 ms、終了 1200 ms とし、基本 CW=wheel down、CCW=wheel up を保存してください。Studio のキー配置だけを初期化しても DYA 設定は残ります。settings-reset は不要です。

通常更新は Studio 保存済み配置を保持します。新しい初期配置を使う場合は先にエクスポートし、Studio で初期配置に戻してください。settings-reset は不要です。記号は通常の US キーコードで、出力文字は PC 配列に依存します。

**L1 Mouse の左 41（4 行目・1 列目、左下の Base Ctrl 位置）**を押す間、DYA の通常速度の 1/4 になり、離すと通常速度に戻ります。Base Ctrl、方向、スクロール設定は保持します。Studio に配置を保存済みの場合、この L1 位置に **Precision 0.25x (hold)** を割り当てて保存してください。配置全体の初期化や settings-reset は不要です。

## LED とバッテリー

右の赤 LED は選択中の PC Bluetooth を示します。待機中は 2 秒ごとに 100 ms、最大 30 秒点滅し、接続時は 2 秒点灯後に消灯します。左は左右間接続ではなく自身の電池低下だけを示します。各側の推定電池残量が 15% 以下で 30 秒ごとに 100 ms 点灯し、20% 以上で解除します。USB 給電中は低電池表示を抑制し、アイドル／スリープでは赤を消灯します。待機表示の終了で広告は停止しません。有線出力では不要な Bluetooth 待機表示を行いません。

青はハードウェアの充電周期表示です。通常の最初の充電周期終了で消灯しますが、消灯だけでは満充電を保証しません。推定 100% から満充電 LED を生成しません。[詳細と制限](docs/led-status.md)。

電池は既存の一つのサンプラーを使い、活動中 60 秒間隔、アイドルで停止、復帰後は新しい結果を待ちます。LED は ADC ポーリングや偽の入力を追加しません。本版は左右とも更新が必要です。reset は不要で、ペアリングと Studio／DYA 設定を保持します。

## 省電力と復帰

- 無入力 **30 秒**でアイドル状態になり、Bluetooth を維持します。
- バッテリー動作中、無入力 **15 分**でディープスリープに入ります。スリープ中の左右それぞれでキーを押し、Bluetooth の再接続を待ちます。トラックボールやエンコーダーの回転による復帰は保証しません。
- USB 給電中の側は USB／Studio 用に起動状態を保ちます。スリープでは RAM 内の未保存編集が失われるため、Studio の変更を保存してください。
- トラックボールは MOTION 割り込みと既存のセンサー休止設定を使用します。実際の消費電流と復帰動作は実機で確認してください。
- BLE では移動量を保持し、レポートを最低 **8 ms** 間隔にまとめます。USB は即時出力を維持します。右側は **7.5 ms** の接続間隔とゼロの peripheral latency を要求しますが、実際の値はホストが決定します。接続待機中の消費電力が増える可能性があり、滑らかさと消費電流の実機確認が必要です。
